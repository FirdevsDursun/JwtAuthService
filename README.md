# 🔐 JWT Authentication & Refresh Token Microservice

.NET 8 Web API ile geliştirilmiş, rol tabanlı yetkilendirme, Refresh Token rotation mimarisi ve modern bir dashboard arayüzü içeren enterprise seviyesinde kimlik doğrulama servisi.

## 🚀 Öne Çıkan Özellikler

- **.NET 8 Web API & Clean Architecture**
- **JWT (JSON Web Token) Access & Refresh Token Yönetimi**
- **Entity Framework Core & SQL Server Entegrasyonu**
- **HMAC-SHA256 Şifre Hashleme**
- **Vanilla JS + Glassmorphism CSS ile Modern Dashboard UI**
- **OpenAPI / Swagger UI Entegrasyonu**
